# 发布清单

## 构建前

- [ ] `npm run typecheck` 通过
- [ ] `npm run lint` 通过
- [ ] `npm run test` 通过（含 SSE、URL、幂等、隔离、迁移、页面无头渲染）
- [ ] app.json 中包标识、版本号、图标与启动图已确认
- [ ] 发布构建关闭私网 HTTP 调试开关
- [ ] 未把任何 API Key、签名、推送证书写入仓库或 CI 产物

## Android 外部入口（真机）

- [ ] 长按图标出现三个快捷方式，点击都能进对应页面
- [ ] `adb shell am start -a android.intent.action.VIEW -d "myhermes://send?text=hi"` 能预填输入框
- [ ] 从浏览器/微信分享文本到 MyHermes，预填且不自动发送
- [ ] 分享图片后附件出现在预览条，且体积被压缩
- [ ] 剪贴板快捷方式在 Android 10+ 能读到内容（读不到时给提示）

## 真机冒烟

- [ ] 首次启动 → 添加实例 → 90 秒内发出第一条消息
- [ ] 至少 3 个实例，切换不串会话/缓存/Run
- [ ] 流式文本、工具卡片、终态显示正确
- [ ] 停止按钮只在服务端确认后显示已取消
- [ ] 断网 15 秒恢复：不重复执行命令
- [ ] 杀进程重开：恢复活跃 Run 状态与历史一致
- [ ] 审批“允许一次”与“拒绝”分支；旧 prompt 不能再次批准
- [ ] 401 / 404 / 409 / 429 / 503 均有明确文案
- [ ] 诊断报告复制后不含 Key 与正文
- [ ] 删除实例后不再持有其密钥引用

## 已知限制（首版）

- 后台不保证持续 SSE；锁屏完成通知需自托管通知桥（未实现）
- 未启用 SQLCipher；依赖系统文件保护
- 图片附件仅 `openai_compat` 模式；缩略图预览与相册权限需真机回归
- 不做 App 内语音输入（系统键盘听写已覆盖）；不支持任意文件上传
- Jobs 只映射已知字段；diff 只识别 unified diff；冲突对照只做本地视图清理，不改服务器状态
- 会话搜索只查本地缓存（无服务端搜索接口）；模型选择不保证服务器采用所选模型
- 不支持接管微信/Telegram 等其他入口所属会话（服务端 409）
- 未在真实 Hermes 实例与真机上验收前，不宣称兼容所有版本
